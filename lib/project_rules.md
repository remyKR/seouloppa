# Seouloppa 프로젝트 규칙

## 🎯 프로젝트 개요
- **앱 이름**: Seouloppa (서울오빠)
- **목적**: 한국 남성과 외국인 여성 매칭 플랫폼
- **타겟**: 한국 문화에 관심 있는 외국인 여성 & 국제 교류를 원하는 한국 남성

## 📁 폴더 구조 (법칙 7 준수)
```
lib/
├── views/          # UI 화면 (페이지별)
│   ├── auth/       # 로그인, 회원가입
│   ├── profile/    # 프로필 관련
│   └── matching/   # 매칭 관련
├── models/         # 데이터 모델
├── services/       # 비즈니스 로직, API 호출
├── widgets/        # 재사용 가능한 위젯
└── utils/          # 유틸리티 함수
```

## 🔑 핵심 기능
1. **회원가입 플로우**
   - 기본정보 입력 (닉네임, 생년월일, 성별)
   - 프로필 사진/동영상 업로드
   - Google Cloud Vision API 얼굴 인증
   - 자기소개 작성 (키, 체형, 국적, MBTI, 언어)

2. **매칭 시스템**
   - 프로필 탐색
   - 좋아요/패스 기능
   - 매칭 알림
   - 채팅 기능

3. **안전 기능**
   - 얼굴 인증 필수
   - 신고 시스템
   - 프로필 검증

## 🎨 UI/UX 원칙
- Figma 디자인 100% 준수
- Material Icons 사용 금지 (SVG/이미지 에셋만 사용)
- 한국적 색상과 디자인 요소 활용
- 다국어 지원 (한국어/영어 우선)

## 🔒 보안 원칙
- 모든 API 키는 환경변수 사용
- 사용자 개인정보 암호화
- HTTPS 통신만 허용
- 토큰 기반 인증

## 📱 플랫폼 지원
- iOS 13.0 이상 (우선)
- Android 21 이상
- 태블릿 대응 고려

## 🚀 개발 우선순위
1. iOS 네이티브 기능 최적화
2. 회원가입 플로우 완성
3. 기본 매칭 기능
4. 채팅 시스템
5. 알림 시스템
